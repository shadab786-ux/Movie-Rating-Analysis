<h1>This is movie rating analysis using python Visualization</h1>
<h2> Project Overview</h2>
<p>This project provides an exploratory data analysis (EDA) of movie ratings, genres, popularity, and financial performance using Python. By analyzing a dataset of 650 movies spanning from 2000 to 2025, the goal is to discover trends, uncover correlations between ratings and user engagement, and highlight top-performing genres and films through clear visual representations.</p>
<h2>Key Objectives</h2>
<p>1)Analyze the distribution of movies across different genres.
2)Calculate and compare average ratings per genre.
3)Identify release years with the highest movie counts and average popularity (votes).
4)Analyze distribution trends in movie ratings and runtimes.
5)Examine the correlation between financial metrics (Budget vs. Revenue) and user ratings.
6)Present insights using clear Matplotlib and Seaborn visualizations.</p>
